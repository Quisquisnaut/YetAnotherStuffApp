YetAnotherStuffApp for Windows - quick setup
============================================

1. Install Python 3 (once)
   - Microsoft Store: search "Python 3.12" (or newer) and click Get, or
   - https://www.python.org/downloads/windows/ : run the installer and tick
     "Add python.exe to PATH" on the first screen.
   Nothing else is needed (the app uses only the Python standard library).

2. Unzip the app
   Right-click the zip > Extract All... and choose a folder you own, e.g.
   Documents\YetAnotherStuffApp (not "Program Files": the app keeps its
   data next to itself unless you choose another data folder).

3. Start it
   Double-click "Start Stuff App.bat".
   (Or open a terminal in the folder and type:  py main.py)
   If Windows SmartScreen asks, click "More info" > "Run anyway".
   Tip: right-click the .bat > Send to > Desktop (create shortcut).

4. Use it
   The app opens a desktop window (Tkinter). Start with Help > User guide,
   or New box, then New item. The window title and Help > About show the
   version. Close the window or choose File > Exit to quit.
   For text menus, open a terminal in the app folder and run:
       "Start Stuff App.bat" --console
   Type a choice number and press Enter (0 = back/exit). If Tkinter or a
   graphical display is unavailable, text menus are used automatically.
   To display the version without opening data: py -3 main.py --version
   - Your data is in the StuffData folder next to the app. To keep it in
     another folder, use Tools > Settings (console: Settings: data folder),
     or start with:
         py main.py --data "%USERPROFILE%\OneDrive\StuffData"
   - Exports (PDF / Markdown) open with your default viewer.
   - To import an item text file or photos, put them in the app folder
     (they are listed) or type their full path.
   - Optional: "py -m pip install pillow" lets the app import PNG photos
     (without it, JPEG photos only).

5. Update
   Close the app. Make an independent copy of the complete StuffData folder
   and stuffapp_settings.json, then replace only app code from the ZIP.
   The ZIP contains no inventory or device settings; keep yours in place.
   Test new builds in a separate folder with --data pointing to an empty
   test folder. Do not merge inventories by copying over each other.

This ZIP requires Python. It is not a standalone .exe. Test packages are
not approved releases. BUILD-INFO.json identifies the version, Step 00,
base commit and SHA-256 file inventory (including uncommitted app changes).
iCloud folder recognition on iPhone does not establish synchronization
with Windows. Avoid simultaneous edits on multiple devices.
